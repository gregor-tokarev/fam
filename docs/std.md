# Standard bundles

Generated with `go run ./cmd/fam internal std-docs`. Do not edit this file.

Import `@fam/std.pkl`, then select a bundle, for example `bundles { std.computer.agentBrowser }`.
The tables use fixed Linux facts: Ubuntu 26.04, amd64. Skills can differ on other platforms.
A bundle lists secret names. The config supplies their values.
FAM skips unsupported bundles. The last column gives the reason when a bundle does not support a machine.
